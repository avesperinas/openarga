# OpenArga v0.1.0

OpenArga is a self-hosted personal operating system: one place for your training, health, food,
money, calendar, trips, books, notes and plans. Every app is a module on a small kernel, your data
stays in your own Postgres, and your AI reads and acts on it only through tools you allow.

This is the first public release. It is the open edition of a private system that has been in
daily use for months.

## The fifteen apps

| App | What it does |
|---|---|
| Training | Strength training, one tap per set, and what the history says |
| Health | Steps, sleep, heart, weight and lab results |
| Nutrition | What you eat and drink, with its macros and micros |
| Recipes | Your home cookbook and pantry, with the nutrition worked out |
| Shopping | The shopping list that remembers what you buy |
| Finance | Accounts, investments, shared expenses and what everything is worth |
| Goals | Goals, habits and tasks |
| Calendar | Your events, holidays, sports fixtures and any iCal |
| Outings | What is on near you, and what you want to do |
| Travel | Trip ideas, plans and the trips you made |
| Books | The books you read and want to read |
| Notes | Your notes, linked, with a Git backup |
| Study | Courses, classes, exams and grades |
| Insights | What your data says, every day and every week |
| Connections | Everything that comes from outside, in one place |

Every app ships in English and Spanish, and each person picks their own language, time zone,
currency, region and home area in Settings.

## Install

You need Docker with Compose and about 4 GB of RAM.

```bash
git clone https://github.com/avesperinas/openarga && cd openarga
scripts/stack-env.sh > .env              # a random value for every password, secret and token
docker compose up -d --build --wait
```

Open `http://localhost:8000` and sign in as `admin` with the `OPENARGA_ADMIN_PASSWORD` in `.env`.
The first-run wizard asks for your language, region, time zone, currency, home area and the apps
you want. To change the instance (a domain, fewer apps, an AI provider) copy
`openarga.example.yaml` to `openarga.yaml`, edit it and run `uv run python scripts/compose.py`.

## AI is optional

Nothing needs a model to work. When you want one:

- **Anthropic** (Messages API) or any **OpenAI-compatible** endpoint, including a local
  **Ollama**, LM Studio or vLLM.
- Two roles, `fast` and `smart`, so an app asks for a role and never for a provider or a model.
- A monthly token budget for the instance, and each person can bring their own key.
- About three hundred MCP tools, each with its OAuth scope, so Claude or any MCP client can use
  your apps without seeing the schema. A read token cannot write, because the scope is also the
  Postgres role.

Steps for Ollama on the host are in `docs/platform/ai.md`.

## Try the demo

Set `demo: true` in `openarga.yaml` (and `connections: fake` to run with no outside accounts) and
the sign-in page offers Alex, who reads in English, and Sam, who reads in Spanish. They share a
space and have eighteen months of synthetic life in every app. Fill it with
`uv run python scripts/demo.py`.

## What it guarantees

- One Postgres schema and one role per module, and row-level security per person: the database
  enforces isolation, not the code.
- Permission is one chain: OAuth scope, Postgres role.
- Every migration is backward compatible.
- Seeds and tests are synthetic. There is no personal data in the repository.

## Known limitations

- **Tested on Linux with Docker.** Other platforms are untried. The test suites run locally; there
  is no hosted CI yet.
- **Images are built on your machine.** There are no published container images yet.
- **The Insights image downloads its voice models at build time** from Hugging Face, so that build
  needs internet access.
- **Outside sources need your accounts.** Banks, Apple Health and Google Health, calendars and the
  rest are exercised with recorded responses and fixtures; expect rough edges with a real account.
- **Outings knows two areas**, Pamplona and Munich. Others are added as a YAML profile in
  `modules/outings/areas/`.
- **The region picker lists the regions of Spain, Germany, France, Italy, the United Kingdom,
  Belgium and Austria.** For any other country, type the ISO 3166-2 code.
- **English and Spanish only.** Adding a language means a catalog per app.
- **In the demo, what the two people share is written in English**, such as the shopping list and
  the household calendar; what each one owns is written in their language.
- **Phones use the installable web app.** There is no native app.
